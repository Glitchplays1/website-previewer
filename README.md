# Website Previewer

A simple tool that lets you preview websites inside an iframe without navigating away from the page.

## Features
- Enter any website URL
- Instant preview in a browser-like window
- Clean, modern design
- Works on desktop and mobile

## How to use
1. Enable GitHub Pages for this repository:
   - Go to Settings → Pages
   - Under "Build and deployment", select branch `main` and folder `/ (root)`
   - Save
2. Visit: `https://glitchplays1.github.io/website-previewer/`

## Note
Some websites refuse to be embedded in iframes for security reasons (using headers like `X-Frame-Options` or `Content-Security-Policy`). This is normal and cannot be bypassed from the client side.
